#### I'm a Software Engineer with over a decades worth of experience.

## Me

I optimize for simplicity, minimalism, and readability. As Einstein said "Everything should be made as simple as possible, but not simpler".

## Work

I currently work at Belvedere Trading where I help the position and risk team build reliable systems to deliver all desks useful risk management tools and reports.

## Favorite language

I kind of jokingly say my favorite programming language is bash because I love linux and the command line. Check out my [dotfiles](https://github.com/jkleve/dotfiles/tree/main)! Bash gives simple access to so many useful tools and is quite quick to automate something. My true love is C++ for its view of the hardware that you are programming on. It's a simple language that gives you complete control of your system.

## C++ Boilerplate

Want to get started with a C++ app using the bazel build system? See [cpp-bazel-template](https://github.com/jkleve/cpp-bazel-template)

## Older work

Most of my work is done behind closed doors these days but you can check out some older repos I built, mostly for C++11.
- C++11 sqlite3 wrapper to give it a nicer API: [slight](https://github.com/jkleve/slight)
- C++11 OS Abstraction Layer (OSAL) inspired by [NASA's cFS OSAL](https://github.com/nasa/osal): [osal](https://github.com/jkleve/osal)

 🔭 I have a passion for space and studied Aerospace Engineering as my undergrad at Iowa State University. Checkout my [planets repo](https://github.com/jkleve/planets) which plots tle data.
